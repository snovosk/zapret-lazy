# Release notes — zlazy v1.3.8

Обслуживание без перезагрузки, пауза при VPN, более быстрый старт и обновлённый установщик.

## Новое

- **Обслуживание без перезагрузки.** Движок ждёт сеть перед проверкой обновлений
  (при позднем Wi-Fi обновление больше не пропускается, движок не завершается),
  проверяет обновления раз в сутки и после пробуждения компьютера и сверяет
  расписание проверок раз в час. «При запуске Windows» срабатывает и после сна
  дольше 30 минут.
- **Пауза при VPN.** Когда интернет идёт через VPN-туннель, zlazy останавливает
  обход: через VPN он не нужен, а тесты стратегий измеряли бы туннель. В виджете —
  знак паузы и строка `vpn: on · lazy paused`. После отключения VPN (5 с подряд)
  возвращается прежняя стратегия; если VPN включить посреди теста, тест
  прерывается и повторяется после отключения.
- **Быстрый старт.** На загрузке сначала проверяется запомненная стратегия; если
  она прошла все проверки, обход включается сразу, без перебора остальных.
- **Установщик.** Анимированный индикатор перед текстом текущей операции; окна
  результата, ошибки и подтверждения удаления в стиле установщика; больше нет
  белого окна прогресса при распаковке.

## Улучшения

- Стратегия, выбранная вручную в виджете, запоминается до следующего
  тестирования: после перезагрузки включается она, а не прежняя.
- Права доступа (ACL) переписываются только при расхождении — минус ~7 с на старте.
- Трей стартует через 10 с после входа в Windows вместо 45 с.
- Индикатор статуса в виджете всегда на одном месте, текст выровнен влево.
- Ссылка GitHub в меню ведёт на репозиторий проекта.

## Проверка

- Установка 1.3.8 поверх 1.3.7 на этом ПК: пауза при включённом Happ (Wintun)
  через ~3 с после старта движка; выход из паузы → полный тест → установка
  `general (EXP).bat` (36/36); повторное включение VPN → пауза в ту же секунду.
- VPN, включённый на 4-й стратегии из 21: тест прерван, пауза.
- VPN, включённый во время замера без обхода: результат отброшен, пауза.
- Скриптовые проверки: разбор всех скриптов, рендер виджета (run/paused/testing/
  error) и окон установщика.

- Обслуживание: выход из мониторинга по таймеру и по скачку часов (пробуждение),
  решение «пора проверять» для всех расписаний — на заглушках.

Не проверялись живьём: полная перезагрузка Windows, сон/пробуждение и VPN без
системного туннеля (режим прокси) — такой VPN не обнаруживается.
