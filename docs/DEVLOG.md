Entry format (see `docs/CONVENTIONS.md`):
`Area/module | Was | Now | Reason | Verified`

Verification levels used in this project (see `docs/TESTING.md` for the full
methodology):

- `code review` — inspected by a human/agent reviewer, not executed.
- `unit` — executed against fixtures/mocks, no network, no service changes.
- `integration` — executed on an admin test machine, real zapret-core payload,
  real service install/remove.
- `real network` — executed against live blocked targets (Discord/YouTube).
