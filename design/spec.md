# zapret lazy — спецификация виджета

Холст карточки: **278×186 px** (logical). Шрифт: Consolas 9 pt ≈ **11 px** моноширинный
(в макете — JetBrains Mono, метрика 0.6 em ≈ Consolas). Все размеры в px.

## Геометрия карточки (координаты от левого верхнего угла)

- Шапка: 0–26, радиус верхних углов 8; под ней линия `#212226`.
  - логотип: «лиса» 12×12, позиция (10, 7), assets/logo-fox.png (оранжевый
    `#E8720C`, прозрачный фон); тот же знак — ярлык приложения (zapret-icon.ico,
    слои 16–256, лиса на тёмной плашке #131417)
  - заголовок «zapret lazy»: (27, 6), 11 px bold, `#EDEFF3`
  - pin (фиксация окна «поверх всех»): 10×10, позиция (214, 8), силуэт
    канцелярской кнопки заливкой (шляпка-гриб + тонкая игла вниз).
    Виден всегда: обычное состояние — `#9A9BA4`;
    когда окно закреплено — подсвечивается рыжим `#E8720C`;
    hover → `#E8720C`, как у остальных иконок шапки
  - ⋮: 10×12, позиция (236, 7), три точки ⌀2.4, шаг 4
  - ✕: 10×10, позиция (258, 8), штрих 1.2, round cap
- Поле стратегии: (10, 37), 258×22, радиус 5; текст 11 px с отступом 8 слева:
  приписка «strat» приглушена `#8B8C96`, название белым `#E8E9EE`.
  У всех полей-настроек выпадающего окна нет — значение листается скроллом
  влево/вправо с плавной анимацией; вместо chevron справа пара стрелок
  ‹ › : 6×9 каждая, позиции (232, 7) и (244, 7), штрих 1.2, round cap.
- Поля настроек ядра (под стратегией, тот же стиль 258×22, радиус 5, шаг 28):
  - game filter: (10, 65), подпись приглушена `#8B8C96`, значение `#E8E9EE`
    (disabled / enabled);
  - ipset list: (10, 93), значение `#E8E9EE` (none / имя списка).
- Строка статуса: текст по горизонтальному центру окна — бокс (30, 120),
  218×14, выравнивание center; индикатор 11×11 в (20, 121) — по левому отступу карточки.
  В «Проверке» бокс (29, 120), 220×14 — под длинный текст с многоточием.
  В состоянии проверки текст длинный (уходит в «…»): бокс (27, 120), 239 px,
  индикатор (10, 121).
- Строка сети: две пары «адрес + пинг» по центру каждой половины окна —
  боксы (30, 137) и (144, 137), 104×14, выравнивание center.
  Адрес `#9A9BA4`, задержка `#E8720C` bold; таймаут — «—» цветом `#8B8C96`.
- Футер: поле расписания (10, 158), 152×22, радиус 5.
  «zapret v72.2» (версия оригинального zapret) — правый край (268), 11 px, `#8B8C96`, y = 162 (центр поля).

Карточка 278×186. Вертикальный ритм: пузыри 37 / 65 / 93 (шаг 28) и футер 158;
пара текстовых строк отцентрована в зазоре между ipset list и футером
(115–158, центр 136.5): статус 120, сеть 137, межстрочный зазор 13.
Отступ от боковых граней 10 px — одинаковый для «пузырей» и логотипа в шапке;
текстовые строки отцентрованы по горизонтали относительно окна. Капс и разрядка не
используются: все надписи одним кеглем 11 px, иерархия только цветом.
Тексты статуса в нижнем регистре («service: run · upd 12.11 23:44», «testing 5/21…»).

## Меню «⋮» (попап)

- Попап: правый край 268 (под кнопкой ⋮), y = 28; 142×137, радиус 6, стиль как у выпадайки.
- Пункт: высота 24, текст 11 px, отступ слева 12, сверху 6 (вертикальный центр строки).
- Hover («Open logs»): заливка `#35363E`, радиус 4.
- Разделитель: линия `#2E2F36` 1 px, поля 4 по вертикали, 6 по горизонтали.

## Индикаторы состояний (13×13 в наборе, 11×11 в строке статуса)

В строке статуса индикатор уменьшен до 11×11 — по высоте текста. У всех состояний
мягкое свечение своим цветом (blur 4–5, opacity 40–55 %).

- running: круг `#6FCF7A`, свечение blur 5 / 45 %.
- paused: две вертикальные плашки 3×9, радиус 1, `#E8720C` (без обводки-кольца),
  свечение blur 4 / 40 %.
- error: квадрат 12×12, радиус 2, `#D9534F`, свечение blur 5 / 40 %.
- checking: три дуговых сегмента, штрих 1.8 round cap; ведущий сегмент `#FF9A3C`,
  два других `#E8720C`; свечение `#FF9A3C`, blur 5 / 55 %.
  Вращение — анимация на стороне WinForms.

## Длинные строки

Выбрана **обрезка с «…»** (single line, ellipsis): текстовый бокс статуса 239 px.
Пример кадра «Проверка»: «Testing 5/21 — general (FAKE TLS…» (полная строка 48 символов
с реальным именем стратегии 32 символа). Максимум имени стратегии в поле:
«general (FAKE TLS AUTO ALT2).bat» влезает без обрезки (205 px при боксе 224 px).
